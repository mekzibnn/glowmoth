Glowmoth — a little moth lights every lamp in a dark garden. Steer with the mouse or WASD/arrows, dash with Space (dashing through a bat scares it off), collect pollen to build a combo up to ×8, and mind the sticky spider webs. Light every lamp to clear the level; each level adds lamps and faster bats. Three lives, a best score that sticks around, and synthesized sound throughout — no assets, no network, just canvas and WebAudio.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
