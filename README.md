Glowmoth — a little moth lights every lamp in a dark garden. Steer with the mouse or WASD/arrows, dash with Space (dashing through a bat scares it off), collect pollen to build a combo up to ×8, and mind the sticky spider webs. Light every lamp to clear the level — that's the WIN; lose all 3 lives and it's game over. Each level adds lamps and faster bats, and every level the moon changes phase and the garden changes with it: a full moon doubles pollen, a new moon slows the bats, a gibbous moon quickens them. Every 5th level the MOTH-EATER boss hunts you — dash through it 3 times to scare it off for +500. Pollen banks into a shop between levels: +1 Life, Swift Wings, Long Dash, Webproof. A best score that sticks around, and synthesized sound throughout — no assets, no network, just canvas and WebAudio.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
